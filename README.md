# Wantek Photo Portfolio

Website portofolio fotografer untuk Wantek Photo, dibangun menggunakan React, Vite, TypeScript, dan Tailwind CSS.

## Website

Website akan tersedia setelah GitHub Pages diaktifkan:

https://bimaharis-web.github.io/wantekphoto/

## Fitur

- Galeri kategori Beauty, Portrait, dan Product
- Lightbox untuk melihat karya
- Navigasi responsif untuk desktop dan mobile
- Tautan Instagram [@wantekphoto](https://www.instagram.com/wantekphoto/)
- Kontak WhatsApp [0853-7008-0083](https://wa.me/6285370080083)

## Menjalankan Proyek

Pastikan Node.js dan pnpm sudah tersedia.

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
```

Hasil build tersedia di direktori `dist`.
